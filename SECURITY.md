# Security policy

Audiops processes audio on the device and only uses the network to download model files from Hugging Face over HTTPS.

If you find a security problem (for example a way to make the app upload data, run code from a crafted audio or model file, or bypass model verification), please report it privately through [GitHub security advisories](https://github.com/sayedshaun/audiops/security/advisories/new) instead of opening a public issue. You can expect a reply within a week.
